# ForgeMCP 0.2.1

ForgeMCP is distributed on PyPI under the name `forge-cpp-mcp`. The package includes
the compiled MCP Apps widgets and icons. The Python import remains `forgemcp`,
and the server command remains `forgemcp`.

## Installation

Requires Python 3.13 or newer:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install forge-cpp-mcp==0.2.1
.\.venv\Scripts\forgemcp.exe --workspace C:\Projects\Example
```

Before PyPI publication, download the attached wheel and install it instead:

```powershell
.\.venv\Scripts\python.exe -m pip install .\forge_cpp_mcp-0.2.1-py3-none-any.whl
```

On macOS/Linux, use `.venv/bin/python` and `.venv/bin/forgemcp`.
Node.js is needed for source builds; the wheel contains the built frontend.
Install CMake, compilers, Ninja, and clangd separately as required by your workflows.

The capabilities and early-development limitations described in the 0.2.0 release
remain applicable. The attached source distribution can rebuild the wheel and
includes the frontend sources and npm lockfile. `SHA256SUMS` covers both packages.
