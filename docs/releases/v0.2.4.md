# ForgeMCP 0.2.4

This release adds direct execution of already-built test programs with literal
command-line arguments through the new `cmake_run_test` MCP tool.

## Changes

- `cmake_run_test(executable, arguments=null, cwd="project/", timeout={"total":600})`
  runs one explicitly selected test executable inside the project or service-storage
  root. It requires no CMake profile or CTest registration.
- Arguments preserve spaces, empty strings, Unicode, and shell-like characters.
  Execution uses an argument list without a shell; NUL arguments and Windows batch
  files are rejected. Executable and working-directory paths are checked after
  resolution to prevent escaping their selected managed root.
- The process inherits the server environment, closes stdin, and supports total
  and idle timeouts. Cancellation cleans up the directly managed process.
- The result contains qualified command inputs, `error`, and `process_id` for logs
  through `process_get`. Zero exit means success; nonzero exits and process failures
  are reported as errors. A launched process's ID remains available after timeout.
- Added a packaged result widget and backend regression tests for argument handling,
  environment inheritance, working directories, output retention, timeouts,
  cancellation, and invalid inputs.

For example, call `cmake_run_test` with:

```json
{
  "executable": "project/build/debug/tests.exe",
  "arguments": ["--gtest_filter=ExampleSuite.*"],
  "cwd": "project/build/debug",
  "timeout": {"total": 30}
}
```

The direct-run tool uses raw executable exit status. It does not replay toolset or
preset environments, apply CTest properties such as `WILL_FAIL` or fixtures, or
infer framework case/JUnit reports. Use `cmake_test` for CTest-managed execution.
Direct execution does not require CTest 4.4.

## Installation

Requires Python 3.13 or newer:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install forge-cpp-mcp==0.2.4
.\.venv\Scripts\forgemcp.exe --workspace C:\Projects\Example
```

The attached wheel can also be installed directly:

```powershell
.\.venv\Scripts\python.exe -m pip install .\forge_cpp_mcp-0.2.4-py3-none-any.whl
```

On macOS/Linux, use `.venv/bin/python` and `.venv/bin/forgemcp`.
The wheel includes compiled widgets and icons; Node.js is required only for source
builds. Install CMake, compilers, Ninja, and clangd separately as needed.
The attached source distribution includes frontend sources and the npm lockfile;
`SHA256SUMS` covers both packages. Early-development limitations from 0.2.0 remain.
