# ForgeMCP 0.2.0

First public release of ForgeMCP, a local Python MCP server for C and C++ development.

## Included capabilities

- Workspace browsing, file metadata, UTF-8 reads, literal/regex searches, and file mutations.
- CMake configuration, builds, and CTest execution through operator-selected profiles and presets.
- Toolchain discovery from PATH, Visual Studio installations, and explicit operator configuration.
- Read-only clangd diagnostics, hover, definitions, references, and document/workspace symbols.
- Process inspection with selectable transcript lines, time ranges, and output byte budgets.
- Packaged MCP Apps widgets and icons, with structured results and useful text fallback.

## Installation

Requires Python 3.13 or newer. Download the wheel attached to this release, then run:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\forgemcp-0.2.0-py3-none-any.whl
.\.venv\Scripts\forgemcp.exe --workspace C:\Projects\Example
```

On macOS/Linux, use `.venv/bin/python` and `.venv/bin/forgemcp`.
Compiled widgets are included; Node.js is needed only for builds from source.
Install external C/C++ development tools separately. MCP client configuration
examples are in `examples/mcp-clients/` in the repository.

## Current limits

This is an early development release. Public interfaces may change before 1.0.
Quality analysis and debugger operations are not implemented yet.
Workspace scans and output are currently unbounded; process transcripts are
retained in memory for the server lifetime. The process working-directory check
is not an operating-system sandbox. Immutable result resources disappear on restart.

## Release files

- `.whl`: ready-to-install Python package with HTML widgets and icons.
- `.tar.gz`: Python source distribution including frontend sources and the npm lockfile.
- `SHA256SUMS`: checksums for the two distribution files.

The source distribution can rebuild the wheel with Python and Node.js.
PyPI publication is a separate final step; a GitHub release does not publish to PyPI.
