# ForgeMCP 0.4.0

This release adds Git workflows to the workspace and local administration panel,
with readable result widgets and coordinated CMake/clangd updates.

## Changes

- Inspect status, staged/unstaged/revision diffs, history, commit details, blame,
  branches, tags, configured remotes, and base/ours/theirs conflict stages.
- Stage and unstage explicit paths, commit or amend, restore files, manage local
  branches, switch branches, and list/save/apply/pop/drop stashes.
- Fetch, pull, and push through the installed Git configuration. Pull defaults to
  fast-forward only; merge/rebase are explicit. History-replacing pushes require
  the expected full remote object ID. Normal hooks and credential helpers remain enabled.
- Merge, rebase, cherry-pick, and revert, including explicit continue/abort/skip
  and recovery of unfinished operations across server restarts.
- Run one instance per worktree, including linked worktrees whose administrative
  data lives outside the workspace. Worktree creation and management remain with
  the client. Workspace file access restrictions are unchanged.
- Coordinate controlled Git source changes through CMake input checks and the
  existing CMake-to-clangd subscription. Report analysis refresh failures
  separately from completed Git operations.
- Display compact Git status, subject-first history, file-grouped patches with
  line numbers and wrapping controls, blame attribution, and explicit conflict
  stages. Local search, original-value copying, expandable complete fields, and
  original JSON remain available in light/dark themes and narrow containers.
- Retain status and commit snapshots for resources, completions, and administration
  monitoring without additional Git probes.
- Terminate managed child processes when cancelled, including reparented Windows
  Git hook descendants through an owned Job Object where supported.

Git commands are bounded and run only in the configured repository root. No
arbitrary Git command, clone, or init tool is exposed. Select the operator Git
toolset with `--git-toolset ID_OR_NAME` (default: `system`).

## Installation

Requires Python 3.13 or newer. Install the attached wheel:

```powershell
python -m pip install forge_cpp_mcp-0.4.0-py3-none-any.whl
forgemcp --workspace C:\Projects\Example
```

The wheel contains the compiled widgets, administration panel, and icons. Node.js
is needed only for source builds. Install Git and any required C/C++ tools separately.
The source archive includes frontend inputs and the npm lockfile; `SHA256SUMS`
covers both distribution files. Existing early-development limitations remain.
