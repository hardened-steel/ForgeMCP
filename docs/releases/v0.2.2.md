# ForgeMCP 0.2.2

This release improves Workspace paths, search output, and readable tool results.

## Changes

- Workspace tool paths accept project-relative values such as `src/main.cpp`,
  `./src/main.cpp`, and `./`. Managed paths accept one trailing slash. Results
  retain canonical `project/...` and `storage/...` paths.
- All tools return readable English plain text alongside typed structured output.
  Source excerpts include line numbers; trees and diagnostics use familiar text
  layouts. Widgets retain their structured data and result-resource links.
- Workspace text search returns at most `max_matches` matching lines (default 100),
  while scanning to compute exact counts. Complete skipped-file details are linked
  through an immutable result resource and shown in the widget's skipped-files tab.
- Added client agent-instruction examples for Codex and Claude Code.
- Improved Python API documentation and process exception handling.

## API change

The `workspace_search` tool is renamed to `workspace_text_search`. Update saved tool
calls and client instructions to use the new name. The search resource URI remains
`forgemcp://workspace/search`.

## Installation

Requires Python 3.13 or newer:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install forge-cpp-mcp==0.2.2
.\.venv\Scripts\forgemcp.exe --workspace C:\Projects\Example
```

The attached wheel can also be installed directly:

```powershell
.\.venv\Scripts\python.exe -m pip install .\forge_cpp_mcp-0.2.2-py3-none-any.whl
```

On macOS/Linux, use `.venv/bin/python` and `.venv/bin/forgemcp`.
The wheel includes compiled widgets and icons; Node.js is required only for source
builds. Install CMake, compilers, Ninja, and clangd separately as needed.
The attached source distribution includes frontend sources and the npm lockfile;
`SHA256SUMS` covers both packages. Early-development limitations from 0.2.0 remain.
