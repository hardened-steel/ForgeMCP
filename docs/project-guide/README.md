# ForgeMCP project guide

Откройте [index.html](index.html) в браузере или панели предпросмотра Codex.

Это самостоятельный статический набор страниц, описывающий ForgeMCP от общей
архитектуры до модулей и классов. Все диаграммы встроены в HTML/SVG, внешний
JavaScript и сеть не требуются.

Страницы:

- `index.html` — общая картина;
- `architecture.html` — слои и зависимости;
- `workflows.html` — последовательности действий;
- `algorithms.html` — структуры данных и ключевые алгоритмы;
- `modules.html` — каталог пакетов, файлов и классов.
