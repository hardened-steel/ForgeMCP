Самостоятельная документация проекта

Безопасный «пульт управления» C++‑проектом для ИИ

ForgeMCP — сервер-посредник. Он принимает структурированные запросы от ассистента и даёт ему строго ограниченный доступ к рабочей папке, CMake, clangd, отладчику и инструментам качества.

Ядро: собирает приложение и жизненный цикл7 встроенных плагинов: функции сервера66 MCP-инструментов: проверяемая поверхностьГлавный принцип: данные ограничены, побочные эффекты явны

Одна фраза

Проект разделён по ответственности, а не по протоколам

Внешний протокол MCP живёт только у входа. Внутри каждый модуль работает с обычными моделями данных: путями, снимками файлов, диагностикой, задачами и статусами. Поэтому CMake, clangd и отладчик не знают, каким клиентом был вызван сервер.

1. Вход

server.py переводит MCP-запрос в вызов зарегистрированного инструмента. Он не содержит CMake- или clangd-логики.

2. Сборка

core/ один раз строит конфигурацию, реестр сервисов, журнал, политики запуска и подключает плагины.

3. Возможности

Плагины Workspace, CMake, clangd, Debugger, Quality, Project и Discovery предоставляют предметные операции.

Карта системы

вызовизолированная предметная возможность
Что проект намеренно не делает. Он не является песочницей для чужого C++ кода. Configure, build, test и debug запускают доверенный проектный код. Зато ForgeMCP строго ограничивает путь, формат запроса, объём данных и разрешённые исполняемые файлы.
