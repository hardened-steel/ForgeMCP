Core и контракт плагинов

ФайлГлавные типыРоль
core/application.pyForgeApplication, LifecycleStateComposition root: создаёт services, подключает 7 built-in plugins, запускает/останавливает их и runtime в безопасном порядке.
core/config.pyForgeConfig, ConfigurationSourceНеизменяемая конфигурация, один раз собранная из CLI → environment → defaults; сохраняет только безопасные метки происхождения.
core/services.pyServiceRegistryНебольшой именованный dependency container: запрет двойной регистрации, стабильный порядок имён.
plugins/contract.pyForgePlugin, PluginContext, ToolExecutionContext, ProgressUpdateTransport-neutral API расширения: инструменты, progress, ресурсы, prompts и completion.
plugins/manager.pyPluginManagerДетерминированно запускает/сворачивает плагины, выполняет rollback при частичном старте, управляет внешними allow-listed plugins.

Workspace: единственная запись

ФайлГлавные типыРоль
workspace/policy.pyWorkspacePolicyНормализует только допустимые workspace-relative пути; запрещает выход наружу, symlink/reparse, binary и игнорируемые зоны.
workspace/service.pyWorkspaceService, WorkspaceTextEdit, ValidatedExecutionPathЛистинг, чтение, snapshots, unified patch и staged text edits; служит CMake/Quality источником проверенных путей.
workspace/events.pyWorkspaceMutationBus, WorkspaceMutationBatchОграниченная application-local шина content-free сообщений о подтверждённом commit.
workspace/plugin.pyWorkspacePluginПубликует 5 инструментов workspace__* и ресурс с постраничным манифестом.

CMake, процессы и toolchain

Пакет / файлГлавные типыРоль
cmake/service.pyCMakeServicePresets, kits, build trees, configure, File API targets, build и CTest. Хранит безопасный кэш профиля и его freshness.
cmake/events.pyCompilationDatabaseRegistryПередаёт clangd только валидированный status/fingerprint compilation database.
processes/runtime.pyProcessRuntimeУнифицированный запуск без shell, bounded output, timeout/cancellation и владение деревом процессов.
toolchain/discovery.pyToolchainDiscoveryServiceВыбирает и проверяет CMake/CTest/компиляторы/LLVM-инструменты; создаёт path-free CMake kits.

clangd и LSP

ФайлГлавные типыРоль
lsp/client.pyLspClient, LspClientStateНизкоуровневый JSON-RPC клиент: framing, запросы/уведомления, shutdown и обработка ошибок протокола.
lsp/positions.pyPositionEncodingПереводит позиции Forge ↔ LSP, учитывая UTF-8/UTF-16 unit encoding.
clangd/service.pyClangdService, _DocumentStateУправляет одним clangd-сеансом, document synchronization, диагностикой, навигацией, completion, rename/actions/format и короткими handles иерархий.
clangd/models.pyClangdStatus, NavigationResult, WorkspaceEditSummaryНейтральные публичные результаты, без LSP-типа в контракте.

Debugger и DAP

ФайлГлавные типыРоль
dap/framing.pyread_message, frame_messageБезопасное Content-Length framing DAP с лимитом сообщения.
dap/client.pyDapClient, DapClientStateКонкурентные DAP-запросы с сопоставлением sequence и независимой bounded-очередью events/reverse requests.
debugger/backends/lldb_dap.pyLldbDapBackendУзкая реализация launch-only разрешённого LLDB-DAP; не общий debugger proxy.
debugger/service.pyDebuggerService, _HandleCache, _EventStoreОдна launch-сессия, state checks, breakpoint/execution/inspection и paged events; устаревшие handles инвалидируются.

Quality

ФайлГлавный типРоль
quality/clang_format.pyClangFormatServiceПолучает XML-замены clang-format через stdin, преобразует offsets и применяет CAS edit. Никогда не запускает clang-format -i.
quality/clang_tidy.pyClangTidyServiceЗапускает строгий clang-tidy поверх валидированной базы компиляции; возвращает ограниченные workspace diagnostics, без fixes.
quality/sanitizer.pySanitizerReportParserRead-only parser переданного ASan/UBSan текста; не запускает бинарник и не скачивает символы.

Project и Discovery

ФайлГлавные типыРоль
project/service.pyProjectStatusServiceОдновременно агрегирует bounded cached providers; возвращает partial/freshness вместо запуска новых действий.
project/registry.pyProjectStatusRegistryРегистрирует провайдеры Core, Workspace, Process Runtime и плагинов, нормализует их модели.
discovery/plugin.pyDiscoveryPluginПять фиксированных workflow-prompts и authored instructions; отделяет их от project-controlled данных.
plugins/surface.pyDiscoverySurfaceRegistryОграниченный registry ресурсов, templates, prompts и completions: timeout, capacity, schema и UTF-8 JSON лимиты.
Технический summary: каталог покрывает src/forgemcp. Контракты результатов расположены в models/ и локальных models.py; тесты с теми же именами модулей находятся в tests/.
